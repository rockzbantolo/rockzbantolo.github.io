Technical Case Study 1

MIS Legacy Database Optimization

Scale: Legacy MIS Tables

Workflow: Legacy MIS tables → Query review → Indexes / normalization → Procedures / functions → Events / triggers → Faster data access

Technical Implementation

  • Reviewed the legacy MIS database and identified unoptimized tables, redundant functions, manual string concatenation, and inefficient SQL calls.
  • Added and adjusted indexes where they supported common operational lookups and reduced unnecessary table scanning.
  • Reworked data access around stored procedures and properly structured SQL calls instead of assembling queries through manual string concatenation.
  • Normalized tables where the existing structure created duplicated or unnecessarily repeated data, while keeping changes aligned with application workflows.
  • Used scheduled database events for recurring data operations and triggers for specific data changes requiring automatic updates.
Measurable Outcome: Improved maintainability and responsiveness of selected MIS database operations through targeted indexing, optimized SQL access, stored procedures, normalization, events, and triggers.
Technical Case Study 2

MIS Data Reconciliation & Terminal Inventory Synchronization

15,000+ Records / 1 Month

Workflow: Corrected Excel master → SQL staging tables → Validation checks → Transactional batch updates → Daily operational reconciliation → Synchronized MIS inventory

Technical Implementation

  • Created a corrected master dataset in Excel containing validated terminal, merchant, SIM, representative, and address information.
  • Coordinated with Operations team leads and system users to compare, validate, and reconcile database records against actual operational records.
  • Imported validated Excel data into temporary SQL staging tables before modifying primary data.
  • Developed SQL batch-update processes to efficiently process the large volume of corrected records.
  • Implemented validation checks to detect terminals already installed or assigned before applying updates.
  • Used database transactions with COMMIT/ROLLBACK to ensure batch updates were atomic and prevent partial or inconsistent updates.
Measurable Outcome: Successfully reconciled and synchronized 15,000+ terminal and merchant records within approximately one month, establishing a reliable foundation for ongoing inventory management.
